갤러리 모니터 v80 — PySide6 사용 안내
==================================

1. GalleryMonitor.exe를 실행합니다.
2. 대시보드의 모니터링 게시판 주소 및 주기를 확인합니다.
3. '알림 규칙'에서 제목·본문·댓글 키워드와 알림 유형을 설정합니다.
4. '텔레그램'에서 Bot Token과 Chat ID를 입력합니다.
5. 상단의 [설정 저장]을 누른 다음 [시작]을 누릅니다.
6. 중지하려면 [중지]를 누르고 상태가 '중지됨'으로 바뀌는지 확인합니다.
7. '데이터 기록'에서 SQLite에 저장된 이전 기록을 조회할 수 있습니다.

* 모든 설정은 실행 파일 옆 config.json에 보관됩니다.
* 이력은 같은 폴더의 monitor_state.sqlite3에 저장됩니다.
* 기존 v80의 config.json 및 SQLite 파일은 프로그램을 종료하고 백업 후
  새 EXE 파일과 같은 폴더로 옮겨 사용할 수 있습니다.
* 설정 변경은 실행 중인 모니터링에 바로 반영되지 않습니다.
  반드시 중지하고 다시 시작하세요.
* Bot Token은 설정 파일에 평문으로 저장되므로 외부에 공유하지 마세요.

* 오른쪽 실시간 실행 로그에서 모니터링 상태를 확인할 수 있습니다.
* 창 닫기 버튼을 누르면 트레이로 숨겨집니다. 트레이 아이콘을 더블클릭하면 복원되고, 트레이 메뉴의 '프로그램 종료'로 완전히 종료합니다.
